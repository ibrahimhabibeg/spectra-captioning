# Data Schemas

This document defines the schema of the generated data files in the spectra captioning pipeline.

## 1. Crossmatch Cache (Parquet)

The pipeline crossmatches the **Galaxy Mentions** catalog with a **Spectra** catalog (e.g., SDSS or DESI). The resulting dataframe is materialized and saved as a partitioned Parquet file.

### Column Naming Convention
Because we use `lsdb.crossmatch` with `suffix_method="overlapping_columns"` and `suffixes=("_mentions", "_spectra")`:
- **Unique Columns**: Any column present in only one of the datasets retains its original name (e.g., `wiki_entity_id`, `spectrum`, `evidence_quotes`).
- **Overlapping Columns**: Any column present in *both* datasets receives a suffix indicating its source (e.g., `ra` becomes `ra_mentions` and `ra_spectra`).

### Schema Overview
The Parquet file contains a wide, denormalized table where each row represents a single spectral observation crossed with a single paper mention.

| Column Category | Origin | Description | Example Columns |
| :--- | :--- | :--- | :--- |
| **Mentions Metadata** | Galaxy Mentions | Unique metadata about the astronomical object or paper mention. | `wiki_entity_id`, `mention_id`, `arxiv_id`, `evidence_quotes` |
| **Spectra Metadata** | Spectra Catalog | Unique metadata about the spectral observation. | `spectrum`, `redshift`, `vdisp` (depending on SDSS/DESI) |
| **Mention Coordinates** | Galaxy Mentions | Target coordinates from the paper mention. | `ra_mentions`, `dec_mentions` |
| **Spectra Coordinates** | Spectra Catalog | Target coordinates from the spectral observation. | `ra_spectra`, `dec_spectra` |
| **Crossmatch Distance** | LSDB Engine | The distance between the matching coordinates in arcseconds. | `_dist_arcsec` |


## 2. Captions Output (JSONL)

The caption generation pipeline outputs a single `.jsonl` (JSON Lines) file. Each line is a standalone JSON object representing the caption result for a single astronomical object (grouped by `wiki_entity_id`).

### JSON Schema

```json
{
  "object_key": "string",
  "dataset_source": "string",
  "ra": "float",
  "dec": "float",
  "strategy": "string",
  "model": "string",
  "timestamp": "string (ISO-8601)",
  "input": {
    "num_quotes": "integer",
    "num_mentions": "integer"
  },
  "output": {
    "caption": "string",
    "thought_summaries": ["string"],
    "is_insufficient": "boolean"
  },
  "usage": {
    "input_tokens": "integer",
    "output_tokens": "integer",
    "thought_tokens": "integer (or null)",
    "total_tokens": "integer"
  },
  "provenance": {
    "crossmatch_radius_arcsec": "float",
    "prompt_template": "string"
  }
}
```

### Field Definitions & Origins

- `object_key`: The unique identifier for the object, extracted directly from the crossmatch grouping column (usually `wiki_entity_id`).
- `dataset_source`: The name of the spectra catalog used for the crossmatch (e.g., `"sdss"` or `"desi"`), supplied via CLI or config.
- `ra` / `dec`: Basic coordinates for the object, extracted from the first row of the object's `ra_mentions` / `dec_mentions` (or `ra` / `dec` if no suffix is applied).
- `strategy`: The name of the captioning strategy used (e.g., `"quotes_only_v1"`), supplied by the strategy class.
- `model`: The exact Gemini model version used, supplied via CLI or config.
- `timestamp`: The UTC timestamp when the record was constructed.

#### `input` Object
- `num_quotes`: Total count of deduplicated quotes processed for the object.
- `num_mentions`: Count of unique `mention_id`s in the crossmatch partition for this object.

#### `output` Object
- `caption`: The final string generated by the Gemini model.
- `thought_summaries`: A list of strings reflecting the model's internal chain-of-thought (if thinking levels are enabled).
- `is_insufficient`: A boolean flag set to `true` if the caption string exactly equals `"INSUFFICIENT_SPECTRAL_DATA"`.

#### `usage` Object
- `input_tokens` / `output_tokens` / `total_tokens`: Standard billing/usage metrics returned directly from the Gemini API response.
- `thought_tokens`: The portion of `output_tokens` spent on invisible chain-of-thought generation (if supported/enabled).

#### `provenance` Object
- `crossmatch_radius_arcsec`: The search radius parameter injected into `lsdb`, sourced from the config.
- `prompt_template`: The strategy name, acting as a record of which prompt generated the results.
